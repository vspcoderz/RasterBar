About RasterBar

          
One Go binary. A terminal player, a local web UI, and the same visualiser pipeline behind both.

        

        

          

            
How it works

            
The Go process resolves streams with yt-dlp, decodes audio with mpv's audio path and video with ffmpeg, computes the spectrum with a hand-rolled FFT, and draws each frame with the same visualisers the terminal uses. This window receives those frames over one local HTTP stream. The browser is a renderer, not a second player.

            
    
              
  • No Electron, no Tauri, no third-party Go modules.
    • 
              
  • Bound to loopback and protected by a per-run token.
    • 
              
  • Works offline for anything already in the download cache.
    •
